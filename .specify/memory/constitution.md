# Focus List Constitution

## Principles

1. User outcomes and testable acceptance criteria come before implementation.
2. Keep the demo small, accessible, and usable on Expo web and supported Expo Go devices.
3. Tasks are stored locally. Do not collect personal data or add a backend without an approved specification.
4. Test task behavior and verify persistence and error states before presenting changes as complete.
5. Review generated specifications, code, dependencies, and security implications. A human owns acceptance.

## Workflow

Review the specification, plan, and task list before implementation. Keep the scope of each feature explicit and document changes to these principles.
