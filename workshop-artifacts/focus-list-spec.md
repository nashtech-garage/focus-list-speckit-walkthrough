# Focus List: Sample Specification

This is a manually prepared workshop example, not an output claimed to have been generated by Spec Kit. Use it as a reference when reviewing `/speckit-specify` output.

## Problem and scope

An individual needs a small, private list of things to do that works without an account. Support creating, completing, reopening, deleting and filtering tasks on one device. No accounts, synchronization, due dates, reminders, or sharing.

## User stories and acceptance

1. **Capture**: Given a non-empty title, when I add it, then the trimmed title appears as an active task. Whitespace-only input creates nothing. Titles are limited to 120 characters.
2. **Track**: Given a task, when I toggle it, then it switches between active and completed and the counts update.
3. **Find**: Given mixed tasks, selecting All, Active, or Completed shows the matching tasks without changing them.
4. **Remove**: Given a task, when I delete it, then it disappears and the counts update.
5. **Return**: After an ordinary reload or app restart, previously saved tasks and completion states remain on the same device. If storage cannot be read or written, show an error and do not claim changes are saved.

## Constraints

Use an accessible mobile-first interface. Task data is local to the browser or device and is not synchronized. Support empty lists and empty filter results. No authentication or server calls.
